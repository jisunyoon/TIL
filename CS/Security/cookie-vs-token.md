# 쿠키 기반 vs 토큰 기반 인증

쿠키 기반 인증 = 전통적인 세션 방식  
토큰 기반 인증 = JWT

---

## 1. 쿠키 기반 인증 (세션 방식)

서버가 사용자의 정보를 기억하고 있고, 클라이언트에서는 식별자(세션 ID)만 보낸다.

- Stateful (서버가 상태 유지)
- 클라이언트는 식별자만 보유
- 서버에서 세션 삭제하면 즉시 무효화 가능

---

## 2. 토큰 기반 인증 (JWT 방식)

- Stateless (서버 상태 없음)
- 서버가 토큰 저장 안 함 — 매 요청마다 서명만 검증
- 클라이언트가 모든 정보 보유 — 토큰 안에 모든 게 있다
- 즉시 무효화 어려움 — 서버가 발급한 토큰을 기억 못하니 거부 불가  
  → 해결: access token 만료를 짧게 + refresh token을 DB에 저장해서 refresh token 삭제하면 사실상 무효화 가능

---

## 언제 뭘 쓸까

- **쿠키 기반** — 보안 및 즉시 무효화가 필요하거나 규모가 작을 때
- **토큰 기반** — SPA, 여러 서버에 분산, 외부 API 통합할 때
