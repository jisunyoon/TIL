# 같은 숫자는 싫어 (Lv.1, 스택)

- **유형:** 스택 (맨 위 원소와 비교)
- **출처:** 프로그래머스

## 문제

```javascript
// 연속으로 나타나는 숫자는 하나만 남기고 제거 (순서 유지)
function solution(arr) {
  var answer = [];
  return answer;
}

solution([1, 1, 3, 3, 0, 1, 1]);  // [1, 3, 0, 1]
solution([4, 4, 4, 3, 3]);        // [4, 3]
```

## 접근 (왜 스택?)

- "연속 중복 제거"는 **바로 직전에 넣은 값**과만 비교하면 됨
- 스택의 **맨 위(마지막) 원소 = 직전에 넣은 값** → 비교 대상으로 딱
- 흐름:
  1. 배열을 앞에서부터 하나씩 봄
  2. **스택이 비었거나**, 지금 값이 **스택 맨 위와 다르면** → push
  3. 같으면 → 무시 (연속 중복이니까 안 넣음)
- **주의:** `[1,1,3,3,0,1,1]` → `[1,3,0,1]` 처럼 **떨어져 있는 같은 값(뒤의 1)은 남김**
  - "연속"일 때만 제거 → 그래서 "전체 목록"이 아니라 **"바로 직전 값"** 하고만 비교

## 풀이

```javascript
function solution(arr) {
  const answer = [];

  for (const num of arr) {
    if(answer.length === 0 || answer[answer.length - 1] !== num){
      answer.push(num);
    }
  }

  return answer;
}
```

## 자기 점검

- [ ] `[1,1,3,3,0,1,1]` → `[1,3,0,1]` (뒤의 1은 떨어져 있으니 남김)
- [ ] `[4,4,4,3,3]` → `[4,3]`
- [ ] `[0,0,0,0]` → `[0]` (전부 연속 → 하나만)
- [ ] `[5]` → `[5]` (원소 1개)
