# 브라우저 저장소 4종

브라우저에 데이터를 저장하는 4가지 방법과 차이

---

## 한눈에 비교

| | 크기 | 수명 | 서버 전송 | 용도 |
|---|---|---|---|---|
| **Cookie** | ~4KB | 만료일까지 | **매 요청마다 자동 전송** | 로그인/세션 |
| **localStorage** | ~5~10MB | 영구 (직접 지워야 함) | 안 됨 | 테마, 설정값 |
| **sessionStorage** | ~5~10MB | 탭 닫으면 삭제 | 안 됨 | 그 탭 한정 임시값 |
| **IndexedDB** | 대용량 | 영구 | 안 됨 | 오프라인 데이터 |

---

## 각각 쉽게

**Cookie** — 작은 메모지(4KB). 요청할 때마다 서버에 같이 딸려감 → 로그인/세션용.

**localStorage** — 브라우저에 영구 저장되는 서랍. 탭 닫아도 안 사라짐. (테마, 설정값)

**sessionStorage** — 그 탭에서만 쓰는 임시 메모. 탭 닫으면 사라짐.

**IndexedDB** — 큰 데이터 넣는 미니 데이터베이스. 비동기라 화면 안 막음. (오프라인 데이터)

---

> 포인트 — **Cookie만 서버로 자동 전송**된다. 그래서 세션/인증에 쓰이지만, 큰 데이터를 넣으면 매 요청마다 딸려가 낭비. 순수 클라이언트 저장은 Storage / IndexedDB.
