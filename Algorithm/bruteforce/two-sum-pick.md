# 두 개 뽑아서 더하기 (Lv.1, 완전탐색 + Set)

- **유형:** 완전탐색(이중 반복) + Set 중복 제거 + 정렬
- **출처:** 프로그래머스

## 문제

```javascript
// 서로 다른 인덱스의 두 수를 뽑아 더해 만들 수 있는 모든 수를 오름차순 배열로 return
function solution(numbers) {
  // 직접 작성
}

solution([2, 1, 3, 4, 1]); // [2,3,4,5,6,7]
solution([5, 0, 2, 7]);    // [2,5,7,9,12]
```

## 제한사항 읽기

- `numbers` 길이: **2 ~ 100** → 모든 쌍은 최대 `100 × 99 / 2 = 4950`개 → **완전탐색으로 충분**
- 값: 0 ~ 100
- **"서로 다른 인덱스"** = 값이 같아도 인덱스가 다르면 OK
  - `[2,1,3,4,1]`에서 `1 + 1 = 2`가 되는 이유 (1이 두 개 있음)
- 결과는 **중복 제거 + 오름차순**

## 핵심 고민

**① 모든 쌍을 빠짐없이, 중복 없이 어떻게 뽑나?**
- 이중 반복문에서 `j`를 **`i + 1`부터** 시작
- 그러면 `(i, j)`와 `(j, i)`를 한 번만 세게 됨 (조합, 순서 무관)
- `j = 0`부터 돌면 같은 쌍을 두 번 + `i === j`(같은 인덱스)까지 더해버림

**② 합이 겹치면? (`5 = 1+4 = 2+3`)**
- 배열에 그냥 push하면 중복이 생김
- **Set**에 넣으면 중복이 자동으로 사라짐

**③ 정렬**
- Set은 배열이 아니므로 `[...set]` 또는 `Array.from(set)`으로 배열화
- `sort()`를 **인자 없이 쓰면 문자열 기준** 정렬 → `[12, 5, 7]`이 `[12, 5, 7]`처럼 잘못 정렬됨
- 숫자 정렬은 반드시 `sort((a, b) => a - b)`

## 접근

1. 빈 `Set` 준비
2. `i`: `0` ~ `n-2`, `j`: `i+1` ~ `n-1` 이중 반복
3. `set.add(numbers[i] + numbers[j])`
4. `[...set]`로 배열 변환 후 `sort((a, b) => a - b)` 해서 return

## 풀이

```javascript
function solution(numbers) {
    let answer = [];
    for(let i = 0; i < numbers.length; i++){
        for(let j = 0; j < numbers.length; j++){
            if (i === j) continue;
            answer.push(numbers[i] + numbers[j]);
        }
    }
    return [...new Set(answer)].sort((a, b) => a - b);
}
```

## 자기 점검

- [ ] `[2,1,3,4,1]` → `[2,3,4,5,6,7]`
- [ ] `[5,0,2,7]` → `[2,5,7,9,12]`
- [ ] `[0,0]` → `[0]` (원소 2개, 최소 길이)
- [ ] `[1,1,1]` → `[2]` (합이 전부 같음 → 중복 제거 확인)
- [ ] `[5,7,100]` → `[12,105,107]` (두 자리/세 자리 섞임 → 숫자 정렬 확인)
