# 힙 (Heap) & 우선순위 큐

**최댓값/최솟값을 빠르게 꺼내는** 특수 트리와, 그걸로 구현하는 우선순위 큐

---

## 힙 (Heap)

부모-자식 간 크기 규칙이 있는 트리. 꼭대기(루트)에 항상 최소 또는 최대가 온다.

**최소 힙** — 부모 ≤ 자식 (꼭대기가 항상 최솟값)

```
        [1]        ← 항상 제일 작은 값이 위
       /   \
     [3]   [2]
```

**최대 힙** — 부모 ≥ 자식 (꼭대기가 항상 최댓값)

---

## 복잡도

| 연산 | 복잡도 | 이유 |
|---|---|---|
| 꼭대기 값 **보기(peek)** | **O(1)** | 최소/최대가 항상 루트에 있음 |
| **빼내기(pop) / 넣기(push)** | **O(log n)** | 뺀 뒤·넣은 뒤 자리 재정렬 필요 |

> "최솟값이 어디 있는지 아는 건 O(1)이지만, 빼내고 나면 다음 최솟값을 위로 올리는 **재정렬** 때문에 O(log n)."

---

## 우선순위 큐 (Priority Queue)

- 일반 큐는 **FIFO** (온 순서대로)
- **우선순위 큐**는 **우선순위 높은 게 먼저** 나온다
- 이걸 **힙으로 구현** (최소 힙 → 작은 값 먼저 / 최대 힙 → 큰 값 먼저)

> 예: 응급실(위급한 환자 먼저), 다익스트라 최단경로, 작업 스케줄러.
