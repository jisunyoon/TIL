# 브라우저에서 URL을 치면 무슨 일이 일어나?

1. **URL 파싱**  
브라우저가 URL을 분석함. 프로토콜이 HTTP인지 HTTPS인지, 도메인명이 www.naver.com 인지, 경로는 /search, 쿼리는 q=hello 이런식으로 쪼개서 분석한다.

2. **DNS 조회**  
도메인을 IP 주소로 변환해야 한다. 먼저 브라우저 캐시 → OS 캐시 → 라우터 캐시 순서가 진행되고 다 없으면 DNS 서버에 확인

3. **TCP 연결 (3-way-handshake)**  
IP를 알았으니 서버와 연결을 수립한다.  
SYN → SYN+ACK → ACK 과정으로

4. **TLS 핸드셰이크 (HTTPS인 경우)**  
HTTPS라면 TCP 연결 위에 암호화 협상을 추가로 한다.  
어떤 암호화 방식을 쓸지 서로 합의하고 인증서를 확인하는 과정

5. **HTTP 요청**  
연결이 완료되면 브라우저가 서버에 "이 페이지 줘"라는 HTTP 요청을 보냄
```
GET /search?q=hello HTTP/1.1
```

6. **서버 응답**  
서버가 요청을 처리하고 HTML, 상태코드 (200 OK 등), 헤더에 정보를 담아서 응답한다.

7. **브라우저 렌더링**  
여기서부터 프론트엔드 핵심 영역! HTML을 파싱해서 DOM 트리를 만들고, CSS를 파싱해서 CSSOM 트리를 만들고, 둘을 합쳐 렌더 트리를 만듭니다. 그리고 레이아웃을 계산하고 마지막으로 페인트를 합니다.
