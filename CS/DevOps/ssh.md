# SSH (Secure Shell)

멀리 있는 컴퓨터(서버)에 **암호화된 통로로 안전하게 접속해서 명령을 내리는 방법**

---

## 개념

- 내 컴퓨터에서 클라우드 서버에 접속하려면 통로가 필요한데, 그 통로를 **암호화**해서 중간에 엿봐도 안 보이게 해주는 것이 SSH
- Termius가 바로 이 SSH로 서버에 연결해주는 도구
- 접속하면 서버 안의 터미널을 내 화면에서 쓰는 것처럼 됨 → `cd`, `ls`, `docker` 등 실행

---

## 접속 방식 두 가지

| 방식 | 설명 |
|---|---|
| 비밀번호 | 접속할 때마다 서버 비번 입력 (편하지만 덜 안전) |
| **키(key) 방식** | 열쇠 한 쌍을 만들어 씀 (실무 표준, 더 안전) |

---

## 키 방식 (ssh-keygen)

`ssh-keygen`으로 **열쇠 한 쌍**을 만든다.

- **개인키 (private)** — 내 컴퓨터에만 보관. **절대 남 주면 안 됨** (내 열쇠)
- **공개키 (public)** — 서버(또는 GitHub)에 등록. 공개돼도 괜찮음 (자물쇠)

**원리** — 서버에 **자물쇠(공개키)**를 걸어두고, 접속할 때 내 **열쇠(개인키)**로 연다.
짝이 맞아야만 열려서, 비밀번호 없이도 안전하게 들어간다.

```
내 컴퓨터 (개인키 보관)  ──암호화된 통로──▶  서버 (공개키 등록됨)
     ssh-keygen으로 키 쌍 생성 → 공개키만 서버 / GitHub에 등록
```

---

## 한 줄 정리

> **SSH = 원격 서버에 암호화된 통로로 접속하는 방법.**
> 실무에선 비번 대신 **개인키(내 것) + 공개키(서버에 등록)** 열쇠 쌍으로 접속한다.
