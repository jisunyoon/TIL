# Core Web Vitals / 캐시 지역성

사용자 체감 성능을 재는 핵심 3지표와, 성능의 바탕이 되는 캐시 개념

---

## Core Web Vitals 3종

| 지표 | 재는 것 | 한마디 |
|---|---|---|
| **LCP** (Largest Contentful Paint) | 가장 큰 콘텐츠가 화면에 뜨기까지 시간 | 얼마나 **빨리 보이나** |
| **CLS** (Cumulative Layout Shift) | 로딩 중 요소가 갑자기 밀리는 정도 | 안 흔들리고 **안정적인가** |
| **INP** (Interaction to Next Paint) | 누르면 반응까지 걸리는 시간 | 누르면 **바로바로 동작하나** |

> INP는 예전 **FID**(First Input Delay)를 대체한 지표. 첫 입력만이 아니라 페이지 전체의 반응성을 잰다.

---

## 캐시 지역성 (Locality)

한 번 접근한 데이터 근처를 또 쓸 확률이 높다는 성질. 캐시가 효과를 내는 근거.

- **시간 지역성** — 한 번 쓴 건 **또 쓸** 확률이 높다
- **공간 지역성** — 방금 쓴 것 **옆에 있는 것**도 같이 쓸 확률이 높다

→ 그래서 **자주 안 바뀌는 건 따로 캐싱**해두면 재접근이 빨라진다.
