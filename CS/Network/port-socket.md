# IP · 포트 · 소켓

데이터가 "어느 컴퓨터의 어느 프로세스"로 갈지 정하는 주소 체계

---

## IP vs 포트

- **IP** = 컴퓨터의 주소 (어느 컴퓨터냐)
- **포트** = 그 컴퓨터의 **어느 프로세스**냐를 알려주는 번호

> 비유: **IP = 건물 주소**, **포트 = 그 건물의 호수.**
> IP로 컴퓨터까지 찾아가고, 포트로 그 안의 어느 프로그램에게 전달할지 정한다.
> (한 컴퓨터에 여러 프로그램이 도니까 포트로 구분)

---

## 주요 포트 번호

| 포트 | 용도 |
|---|---|
| **22** | SSH (원격 서버 접속) |
| **80** | HTTP |
| **443** | HTTPS |
| **3000** | 개발 서버 (React·Node 등 로컬 개발) |

> 80/443/22처럼 **잘 알려진 포트(well-known, 0~1023)**는 관례로 정해진 것.
> `https://naver.com`은 사실 `naver.com:443`인데, 443이 기본이라 생략된 것.

---

## 소켓 (Socket)

**IP + 포트를 합쳐** 실제로 통신하는 연결 창구.
"어느 컴퓨터(IP)의 어느 프로세스(포트)와 연결된 통로"다.

```
192.168.0.1 : 443
   IP         포트     →  이 둘을 합친 게 하나의 소켓
```

> 한 줄: **IP**(컴퓨터 주소) + **포트**(그 안의 프로세스) → 둘을 합친 **소켓**으로 실제 통신한다.
