# 그래프 (Graph)

노드들이 **자유롭게 연결된** 구조. 트리보다 자유롭다 (부모-자식 없고, 순환도 가능).

```
[A]---[B]
 |   / |
[C]---[D]
```

- 예시: SNS 친구 관계, 지하철 노선

---

## 표현하는 2가지 방법

### 인접 리스트 (Adjacency List)

각 노드가 **연결된 애들 목록**을 가짐.

```js
{ A: ['B','C'], B: ['A','D'] }
```

- 메모리 **적게** 씀 → **연결이 적을 때(희소 그래프) 유리**

### 인접 행렬 (Adjacency Matrix)

**표(n×n)로** 연결 여부 표시 (1=연결, 0=아님).

```
    A B C D
A [ 0 1 1 0 ]
B [ 1 0 0 1 ]
...
```

- "A-B 연결됐어?" 확인이 **O(1)**
- 대신 메모리 **많이** 씀 (n×n) → 연결이 많을 때(밀집 그래프) 유리

---

## 비교

| | 메모리 | 연결 확인 | 유리한 상황 |
|---|---|---|---|
| **인접 리스트** | 적음 | 목록 훑어야 함 | 연결 적을 때(희소) |
| **인접 행렬** | 많음 (n×n) | O(1) | 연결 많을 때(밀집) |
