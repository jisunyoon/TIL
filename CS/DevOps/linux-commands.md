# Linux 필수 명령어

배포 서버(리눅스)에서 자주 쓰는 기본 명령어

---

## 탐색 · 확인

| 명령어 | 뜻 | 기억법 |
|---|---|---|
| `ls` | 파일 목록 | list |
| `ls -al` | 숨김 파일까지 상세히 | all + long |
| `cd 경로` | 폴더 이동 | change directory |
| `cd ..` | 상위 폴더로 | `..` = 위로 |
| `pwd` | 현재 위치 확인 | print working dir |
| `cat 파일` | 파일 내용 보기 | 내용 출력 |
| `grep "말" 파일` | 특정 글자 검색 | 검색 |
| `tail -f 로그` | 로그 실시간 보기 | follow (배포 때 필수) |

---

## 파일 다루기

| 명령어 | 뜻 |
|---|---|
| `mkdir 폴더` | 폴더 만들기 |
| `rm 파일` | 삭제 (조심!) |
| `cp 원본 대상` | 복사 |
| `mv 원본 대상` | 이동 / 이름 변경 |

---

> `tail -f`는 배포 후 서버 로그를 실시간으로 지켜볼 때 필수. (`-f` = follow)
