# CSP란?

XSS를 방어하는 방법 중 하나  
"이 페이지에서 어떤 스크립트/리소스를 어디서 불러올 수 있는지" 서버가 응답 헤더로 선언하면 브라우저가 그대로 실행하면서 위반하는 걸 차단해주는 XSS 방어 정책

---

## 동작 방식

1. 클라이언트가 요청을 보냄
2. 서버가 응답에 CSP 헤더를 같이 담아 보냄  
   ex) `Content-Security-Policy: script-src 'self'` → 같은 출처에서 온 스크립트만 허용
3. 브라우저가 그 헤더를 읽고 적용

---

## 다른 보안 도구와의 관계

1. escape로 1차 방어
2. CSP로 2차 방어

CSRF는 SameSite, CSRF 토큰으로 막음
