# 폰켓몬 (실전, 해시맵/Set)

- **유형:** 해시맵 / Set (종류 개수 세기)
- **출처:** 프로그래머스

## 문제

```javascript
// N마리 중 N/2마리를 고를 때, 고를 수 있는 종류 수의 최댓값
function solution(nums) {
  // 직접 작성
}

solution([3, 1, 2, 3]);          // 2
solution([3, 3, 3, 2, 2, 4]);    // 3
solution([3, 3, 3, 2, 2, 2]);    // 2
```

## 접근

- 핵심은 두 값의 싸움:
  1. **뽑을 수 있는 마리 수** = `N / 2` (개수 제한)
  2. **전체 종류 수** = 중복 제거한 개수 (다양성 한계)
- 아무리 종류가 많아도 `N/2`마리밖에 못 뽑고,
  아무리 많이 뽑아도 종류 수보다 많은 종류는 못 가짐
- → **답 = min(종류 수, N/2)**
- 종류 수 세기는 **Set**이 가장 간단 (중복 자동 제거 → 크기가 종류 수)

## 풀이

```javascript
function solution(nums) {

  const maxPick = nums.length / 2
  const kinds = new Set(nums).size;


  return Math.min(maxPick, kinds);
}
```

## 자기 점검

- [ ] `[3,1,2,3]` → `2` (종류 3개지만 2마리만 뽑음)
- [ ] `[3,3,3,2,2,4]` → `3` (종류 3개, 3마리 뽑음)
- [ ] `[3,3,3,2,2,2]` → `2` (종류 2개가 한계)
