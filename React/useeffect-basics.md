# useEffect 동작 원리


## 학습 목표

- 의존성 배열 3가지 패턴 (`[]`, `[값]`, 없음)
- 클린업 함수는 언제 호출되는지
- API fetch 기본 패턴
- 정확히 언제 실행되는지 (렌더링과의 순서)

## 정리
useEffect란 컴포넌트가 렌더링 후에 실행하는 일을 정하는 hook이다.(useEffect로 렌더링 끝난뒤에 따로 처리)
즉 화면을 그리는 것(보여지는 것) 외에 부수적인 작업을 하는 것
=> 사이드 이펙트(부수 효과)
순서
컴포넌트 함수 실행
      ↓
JSX return
      ↓
React가 실제 화면(DOM) 그림
      ↓
useEffect 실행  ← 화면 그려진 다음!

주로 api호출, 타이머, 이벤트 리스터 등을 useEffect안에서 처리한다.

---------------------------------------------

의존성 배열 3가지 패턴 (`[]`, `[값]`, 없음)
1. []빈 배열 -> 처음 한번만 실행 (마운트 때 1번)
2. [값] -> 그 값 바뀔 때마다 실행
3. 없음 -> 매 랜더링마다 실행 (너무 자주 실행되서 위험)

클린업은 useEffect함수가 return하는 함수인데 컴포넌트가 사라질때(언마운트) 실행된다.

클린업 실행 시점
1. 컴포넌트가 사라질 때 (언마운트)
2. 의존성이 바뀌어서 effect가 다시 실행되기 직전

useEffect는 return이 필수 아님.
"켜놓은 것(타이머·리스너·연결)"이 있을 때만 return(클린업)으로 정리.
그냥 데이터 가져오기 정도면 return 없어도 됨.
