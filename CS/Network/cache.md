# 캐시 헤더 + CDN

## 용어 정리

**캐시**: 데이터를 저장해두는 공간/메커니즘

**캐시 헤더**: 브라우저/중간 서버에게 "이 리소스를 어떻게 캐싱해라"라고 지시하는 HTTP 헤더  
즉, 캐시 헤더는 이미지/CSS를 저장하는 곳이 아니라 저장 규칙을 알려주는 표지판  
실제 저장은 브라우저 캐시, CDN 캐시 같은 저장소가 담당한다.

---

**Cache-Control**: 캐시 정책을 지시하는 헤더

**max-age**: Cache-Control 안에 들어가는 지시자 중 하나로 얼마나 오래 캐싱할지

**ETag**: 캐시된 리소스가 아직 유효한지 검증할 때 쓰는 식별자  
서버가 리소스에 고유 식별자를 붙여 전달 → 다음 요청 때 브라우저가 그 값을 같이 보냄 → 서버에서 같으면 304 Not Modified, 다르면 새 리소스 200으로 응답
