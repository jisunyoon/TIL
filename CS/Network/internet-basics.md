# 인터넷 동작 원리

## IP란?

모든 기기들은 고유의 번호를 가지고 있는데 그게 IP 주소

ex) 보통 가정에서 사용하는 IP는 두 종류
- 사설 IP: 공유기가 내부 기기에 부여하는 IP
- 공인 IP: ISP가 제공해주는 실제 인터넷 주소

즉 IP는 각각의 기기들의 고유 주소이고, 도메인은 그 IP를 사람들이 사용하기 쉽게 만든 주소 (ex. naver.com)  
그 중간에서 DNS는 도메인 주소를 → IP로 변경해주는 시스템

사용자가 도메인 입력 → DNS(전화번호부) → 000.000.000.000 → 접속 완료

★ DNS에는 내가 예전에 접속했던 도메인들의 IP가 내 컴퓨터에 임시로 저장되어 있다

★ ISP는 인터넷 연결을 제공하는 통신사 — KT, SKT, LGU+

순서: ISP가 IP 부여 → 내 공유기 → 공유기가 사설 IP 부여 → 내 폰, 내 컴퓨터, 태블릿

## Packet이란?

(쪼개진 데이터 조각조각을 패킷이라고 함)  
모든 인터넷으로 주고 받는 모든 데이터는 다 패킷으로 쪼갠다.

---

## 라우터란?

패킷을 받아서 "어느 방향으로 보낼지" 결정하는 장치

인터넷(ISP) ↔ 공유기(라우터) → 폰, 컴퓨터

1단계 - 인터넷 → 내 ISP의 라우터들이 이 패킷은 저 공인 IP로 방향 결정  
2단계 - 내 집 공유기에서 공유기(라우터)가 이 패킷은 사설 IP(노트북)으로 방향 결정

프록시와 차이:  
내 컴퓨터 → 프록시(대신 요청) → 라우터(길 안내) → 목적지(서버)

---

## 도메인 → IP 변환 흐름

1. 사용자들이 도메인 입력 (naver.com)
2. 컴퓨터가 우선 내 DNS 캐시 찾아봄

있으면?  
3. 공유기(라우터) 통해 IP로 패킷 전달 → naver.com 접속 완료!

없으면?  
3. ISP DNS에 있나 확인 → 없으면  
4. 루트 DNS 서버에 있나 확인 → IP 찾으면  
5. 공유기(라우터)가 패킷 전달  
6. naver.com 접속 완료!

★ 라우터가 전달하는 패킷은 naver.com을 구성하는 HTML, CSS, 이미지 등을 잘게 쪼갠 조각들

★ DNS란 도메인을 IP로 변환해주는 시스템 (ex. 전화번호부)

---

여기까지 요약: 컴퓨터 → 라우터 → 모뎀 → ISP → DNS → 패킷 전송 → 도착
