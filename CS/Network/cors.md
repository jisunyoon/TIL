# CORS 원리와 해결법

Cross-Origin Resource Sharing (교차 출처 리소스 공유)  
브라우저가 다른 출처(origin)의 리소스에 접근하는 것을 제한하는 보안 정책을 완화시켜주는 메커니즘이다.

---

## 출처(origin)란? = Same Origin

프로토콜 + 도메인 + 포트 세 가지가 모두 같아야 같은 출처다.

위의 조건을 벗어나면 위험한 요청일수록 서버가 Preflight로 사전 검증한다.  
서버가 CORS 헤더로 응답 내려주면 → 브라우저 통과 → 정상작동

(프론트가 프록시로 우회해서 사용하는 방식도 있다.)
