# 정렬 (버블 / 퀵 / 병합)

대표 정렬 3가지와 시간 복잡도

---

## 버블 정렬 (Bubble Sort) — O(n²)

옆이랑 비교해 **큰 걸 뒤로 계속 밀기**. 쉽지만 느리다.

```
[3,1,2] → 3>1 바꿈 [1,3,2] → 3>2 바꿈 [1,2,3]
```

---

## 퀵 정렬 (Quick Sort) — 평균 O(n log n)

**기준값(피벗)**을 정하고, 그보다 작은 건 왼쪽·큰 건 오른쪽으로 나눠 반복.

```
[3,1,4,2] → pivot=3 → [1,2] | 3 | [4] → 각각 또 정렬
```

> 피벗을 잘못 고르면(매번 최소/최대값) 반씩이 아니라 1개씩만 걸러져 **최악 O(n²)**.
> (무한 반복은 아님 — 원소는 매번 줄어드니 언젠가 끝나되 느려질 뿐)

---

## 병합 정렬 (Merge Sort) — O(n log n)

**반으로 쪼개고 쪼개서** 낱개로 만든 뒤, **합치면서 정렬**.

```
[3,1,4,2] → [3,1][4,2] → 낱개로 → 합치며 정렬 → [1,3][2,4] → [1,2,3,4]
```

---

## 퀵 vs 병합

| | 퀵 정렬 | 병합 정렬 |
|---|---|---|
| 나누는 기준 | **피벗(기준값)** 기준 분할 | 무조건 **반**으로 분할 |
| 최악의 경우 | **O(n²)** (피벗 잘못 고르면) | 항상 **O(n log n)** 보장 |
| 추가 메모리 | 거의 안 씀 (제자리 정렬) | **O(n)** 더 씀 (합칠 공간) |

> **퀵** = 보통 빠르지만 피벗 운에 따라 최악이 있음.
> **병합** = 항상 안정적이지만 메모리를 더 씀. → 시간 ↔ 공간 트레이드오프.
