# DNS 캐시 / TTL

DNS 캐시 : 한번 찾은 IP를 컴퓨터가 자동으로 임시 저장 (매번 DNS 서버에 물어보지 않음)  
TTL : DNS 캐시의 유통기한 (도메인 주인, 백엔드가 설정함)  
시간이 지나면 캐시 삭제 후 새로 받아옴

---

nslookup : 터미널에서 도메인의 실제 IP를 직접 조회할 수 있는 명령어

```
nslookup naver.com   // naver 서버 IP들이 나옴
```

---

로드 밸런서란?  
사용자가 많아서 서버 여러 대 운영할 때 접속자들을 여러 서버에 분산시켜주는 것
