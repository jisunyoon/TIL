# 트리 / 이진탐색트리(BST) / 순회

부모-자식으로 가지치기하며 연결된 계층 구조와, 그 위에서의 탐색·순회

---

## 트리 (Tree)

데이터가 **부모-자식으로 가지치기하며 연결된 구조**.

```
        [1]         ← 루트(맨 위 시작점)
       /   \
     [2]   [3]      ← 자식
     / \
   [4] [5]          ← 잎/리프(자식 없는 끝)
```

| 용어 | 뜻 |
|---|---|
| **루트 (Root)** | 꼭대기, 맨 위 시작점 |
| **노드 (Node)** | 각 데이터 칸 |
| **잎 / 리프 (Leaf)** | 자식이 없는 끝 노드 |
| **부모 ↔ 자식** | 위아래 연결 관계 |

---

## 이진탐색트리 (BST, Binary Search Tree)

**자식이 최대 2개 + 규칙이 있는 트리.**

> 규칙: **왼쪽 < 부모 < 오른쪽** (왼쪽엔 작은 값, 오른쪽엔 큰 값)

```
        [8]
       /   \
     [3]   [10]
     / \      \
   [1] [6]   [14]
```

이 규칙 덕에 탐색할 때 **한 번 비교할 때마다 반쪽을 통째로 걸러낼 수 있어** O(log n).
(찾는 값이 부모보다 작으면 오른쪽 서브트리는 아예 안 봐도 됨)

> 단, O(log n)은 **균형이 잡혔을 때**. 한쪽으로 치우치게 삽입되면(1→2→3→4…)
> 링크드리스트처럼 일렬이 돼 **최악 O(n)**. → 실무는 AVL·레드블랙 트리로 균형을 자동 유지.

---

## 순회 (Traversal)

모든 노드를 어떤 순서로 방문하냐. **"루트를 언제 방문하냐"**로 3종류로 나뉜다.

```
        [1]
       /   \
     [2]   [3]
     / \
   [4] [5]
```

| 순회 | 순서 | 결과 | 루트 위치 |
|---|---|---|---|
| **전위 (Pre)** | 루트 → 왼쪽 → 오른쪽 | 1 → 2 → 4 → 5 → 3 | 루트 **먼저** |
| **중위 (In)** | 왼쪽 → 루트 → 오른쪽 | 4 → 2 → 5 → 1 → 3 | 루트 **중간** |
| **후위 (Post)** | 왼쪽 → 오른쪽 → 루트 | 4 → 5 → 2 → 3 → 1 | 루트 **마지막** |

> 이름으로 기억: 전(Pre)=루트 먼저 · 중(In)=루트 중간 · 후(Post)=루트 마지막.

**손 추적 요령** — 각 노드에서 "나(루트)·왼쪽·오른쪽"을 정해진 순서로 **재귀적으로 반복**한다.
서브트리로 내려가도 같은 규칙을 그대로 적용하는 게 핵심.

> 참고: BST를 **중위 순회하면 오름차순 정렬**로 나온다 (왼→나→오 = 작은 값부터). 위 BST 예시로 확인해보면 딱 맞음.
