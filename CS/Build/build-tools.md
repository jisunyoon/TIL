# 빌드 도구

작성한 코드를 브라우저가 실제로 잘 돌릴 수 있게 변환·묶어주는 도구들

---

## 문법 변환

**Babel** — 최신 문법을 구형 브라우저용 옛날 문법으로 **번역**(트랜스파일).
ex) 화살표 함수 → 일반 `function`

**Polyfill** — 옛날 브라우저에 **없는 기능 자체를 채워줌**.
ex) `Promise`, `Array.includes`처럼 아예 없는 API를 코드로 구현해 넣음

> 차이 — Babel은 *문법*을 바꿔 쓰고, Polyfill은 *없는 기능*을 새로 채운다.

---

## 번들링

**Webpack** — 흩어진 파일들을 **의존성을 따라 하나로 묶는(번들링)** 도구.

**Vite** — 개발할 땐 안 묶고 브라우저에 바로 줘서 빠름. 빌드할 땐 묶음.
- 개발: 네이티브 ESM으로 필요한 것만 즉시 전달 → 서버 시작이 빠름
- 배포 빌드: 번들링해서 최적화된 결과물 생성

---

## 최적화

**Tree Shaking** — 안 쓰는 코드를 **빌드할 때 털어내는 것**. 최종 번들 크기를 줄인다.
