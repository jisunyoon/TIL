# 스택 vs 큐

데이터를 넣고 빼는 **순서 규칙**이 반대인 두 자료구조

---

## 스택 (Stack) — LIFO

**Last In, First Out** — 나중에 넣은 게 먼저 나온다.

```
push →  [ 3 ]  ← pop (마지막에 넣은 3이 먼저 나옴)
        [ 2 ]
        [ 1 ]
```

- 예시: **뒤로 가기**(브라우저 히스토리), **콜 스택**(함수 호출), 실행 취소(undo)

---

## 큐 (Queue) — FIFO

**First In, First Out** — 먼저 넣은 게 먼저 나온다.

```
enqueue →  [ 1 ][ 2 ][ 3 ]  → dequeue (먼저 넣은 1이 먼저 나옴)
```

- 예시: **프린터 대기열**, 줄 서기(대기열), **태스크 큐**(이벤트 루프)

---

> 한 줄: **스택 = 나중 것 먼저(LIFO)**, **큐 = 먼저 것 먼저(FIFO)**.
